# Comprehensive Statistics

[中文](README.md)

A searchable, filterable, sortable Terraria statistics window for your character career, current-world activity and selected world-wide records. Supports vanilla and modded content, single-player and multiplayer, with Chinese and English interfaces.

## Version and environment

- Current version: **1.3.0**.
- tModLoader 2026.8 Stable · Terraria 1.4.4.9.
- Optional compatibility: ImproveGame >= 1.8.2. Magic Storage >= 0.7.0.11. Both sides must update this mod for multiplayer.

## Features and usage

- **Blocks**: placement and removal of blocks, walls, furniture, circuits and liquids, organized into Blocks, Walls, Circuits and Liquids subtabs.
- **Items**: quantities picked up, crafted and dropped, plus use counts. Tracks the standard interface and Magic Storage, including all newly produced intermediates in recursive chains. Existing stock is not recounted; multiplayer storage crafts require server success confirmation.
- **Other statistics**: ammunition, interactions, kills, economy, fishing (catches, cast outcomes by rod, and bait), movement, deaths and life lost.
- Open with the inventory statistics button or a custom hotkey, then search, filter or sort. Each page saves its own view state.
- Supports ImproveGame construction tools. Hover over `?` beside the Blocks title to see the current session's available capabilities.
- Hover over `?` beside Items for Magic Storage capabilities and multiplayer support. Hold Shift for rules and the number of crafts awaiting confirmation.
- Records activity only after the mod is enabled. Historical recovery, reset, import/export and cross-character merging are unavailable.
