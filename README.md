# 综合统计

[English](README_en.md)

为 Terraria 提供可搜索、筛选、排序的统计窗口，查看角色生涯、当前世界活动和部分世界公共统计。支持原版与模组内容、单人及多人游戏，提供中文和英文界面。

## 版本与环境

- 当前版本：**1.2.0**。
- tModLoader 2026.8 Stable · Terraria 1.4.4.9。
- 可选兼容：ImproveGame >= 1.8.2；联机双方需同步更新本模组。

## 功能与使用

- **物块**：物块、背景墙、家具、电路和液体的放置与移除，分为物块、背景墙、电路、液体四个子页。
- **其他统计**：物品、弹药、交互、击杀、经济、钓鱼（渔获、按鱼竿细分的抛竿结果、鱼饵）、移动、死亡与掉血。
- 从物品栏统计按钮或自定义快捷键打开窗口，搜索、筛选和排序；各页独立保存视图状态。
- 兼容 ImproveGame 的施工工具；在物块标题旁悬停 `?` 查看当前会话可用能力。
- 仅记录启用后的活动，不能补算历史。未提供统计重置、导入导出或跨角色合并。

## 更新说明

- **1.2.0**：物块统计新增液体，并按物块、背景墙、电路和液体分为四个子页。
- **1.1.0**：支持“更好的体验”的施工工具统计。
- **1.0.0**：提供分类统计、搜索筛选和角色数据保存。
