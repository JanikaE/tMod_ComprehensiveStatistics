# 综合统计

[English](README_en.md)

为 Terraria 提供可搜索、筛选、排序的统计窗口，分别查看角色生涯、角色在当前世界中的活动及部分世界公共统计。支持原版与模组内容、单人及多人游戏，提供中文和英文界面。

| 可选兼容 | ImproveGame **>= 1.8.2** |

## 功能与使用

- 记录物块、背景墙、家具、电线和制动器的放置与拆除，以及物品拾取、丢弃、使用、弹药和交易。
- 记录交互、NPC 对话、重铸、护士治疗、经济、钓鱼、鱼饵、移动、死亡、击杀和掉血等活动。
- 从物品栏中的统计按钮打开窗口，按类别查看明细、搜索内容并切换角色统计范围。
- 统计从启用模组后开始；已有历史活动和此前漏计的数据无法补算。

## ImproveGame 兼容

支持“更好的体验”（[ImproveGame](https://github.com/487666123/ImproveGame)）1.8.2 及更高版本。默认后续更新延续当前兼容逻辑，实际发生破坏性变更时再重新适配；运行时仍按方法签名和会话能力判断是否启用。ImproveGame 是可选模组，不安装也可使用综合统计。

覆盖构造魔杖、建造魔杖、空间魔杖、法爆／星爆魔杖、科技魔杖墙工具及内置连锁挖矿。物块页标题旁的 `?` 可查看当前会话实际启用的能力和限制。

多人需客户端与服务器均安装本模组并使用兼容协议，只有服务器确认的施工才入账。客户端施工的单个确认窗口最多观察 8192 格，新家具宽、高均需不超过 32 格；超限或未确认的部分不推算。

## 版本更新说明

### 1.1.0 · 2026-10-29

- **新增 ImproveGame 工具兼容**：将已适配施工工具的实际放置、拆除、清理和批量采掘结果纳入现有统计，支持单人与多人归属、分帧施工及机器人施工。物块页 `?` 提供中英文状态和逐工具能力说明。

### 1.0.0

- 初版统计功能：角色生涯、当前世界切片、世界公共统计、分类明细、搜索筛选、排序、中英文界面及保存重载。
